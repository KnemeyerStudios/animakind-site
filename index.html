The Animakind Specification

This site publishes the machine-readable schemas for the Animakind Specification, as described in the paper Decoupling Persistent AI Identity from Its Execution Substrate: The Animakind Specification by D. Knemeyer.

The specification separates the execution substrate an entity runs on from the persistent identity it carries, and defines records for each. The schemas below are JSON Schema (draft 2020-12). Each schema's $id is the address it is served from.
